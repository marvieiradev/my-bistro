# My Bistro

Projeto de um sistema simples de restaurante.

## Visão geral

O projeto ainda em desenvolvimento

## Stack

- HTML
- CSS
- React
- Javascript
- Tailwind
- Vite

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o ambiente de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Abra o endereço informado no terminal no navegador.
